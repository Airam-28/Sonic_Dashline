# 🦔 Sonic Dashline - Godot 4.3 Modern Engine

![Sonic Dashline Banner](icon2.png)

Sonic Dashline es una modernización técnica y visual de las mecánicas clásicas de Sonic the Hedgehog, desarrollada sobre el motor **Godot 4.3**. El proyecto se centra en ofrecer una experiencia de alta velocidad, con físicas pulidas y una estética premium inspirada en los títulos modernos de la franquicia.

## 🚀 Características Principales

*   **Modern Sonic Physics:** Implementación de físicas de alta precisión para el movimiento, saltos y aceleración.
*   **Sistema de Boost:** Mecánica de turbo con barra de energía funcional, efectos visuales dinámicos y feedback sonoro.
*   **Parallax Backgrounds de 3 Capas:** Un sistema de fondos multicapa para crear una profundidad visual inmersiva.
*   **Pantalla de Victoria Dinámica:** Interfaz de usuario pulida con feedback en tiempo real de anillos recolectados.
*   **Nivel Expandido:** Un diseño de nivel extenso con plataformas flotantes, fosos mortales, resortes y peligros.
*   **Arquitectura Limpia:** Organización profesional de archivos separando Scripts, Escenas (Entities), UI y Assets.

## 🎮 Controles

| Acción | Tecla |
| :--- | :--- |
| **Moverse** | `A` / `D` |
| **Saltar** | `Espacio` |
| **Boost (Turbo)** | `Shift` (Mantener) |
| **Pausar** | `Esc` |
| **Reiniciar** | `R` (En pantallas de fin de juego) |

## 🛠️ Tecnologías Utilizadas

*   **Motor:** Godot 4.3 (Stable)
*   **Lenguaje:** GDScript
*   **Assets:** Sunny Land Assets (Environment) & Custom Sonic Rush Sprites.
*   **Control de Versiones:** Git (GitHub)

## 📁 Estructura del Proyecto

```text
src/
├── core/       # Lógica central y GameManager
├── entities/   # Escenas de objetos (Player, Rings, Goal, etc.)
├── levels/     # Escenas de niveles y entornos
├── scripts/    # Comportamientos específicos de objetos
└── ui/         # Menús, HUD y feedback visual
```
